# Backend (Node.js)

This folder contains a minimal Node.js + Express backend for the blog.

Quick start (requires Node.js >= 14):

1. Install dependencies:

```powershell
cd backend
npm install
```

2. Run in development (requires `nodemon`):

```powershell
npm run dev
```

3. Health check:

Open `http://localhost:4000/api/health`

If Node.js is not installed on your machine, install it from https://nodejs.org/ or use `nvm` / `nvm-windows`.
